# NumPy

`NumPy` (Numerical Python) is one of the most important libraries in [Python](../p/Python.md) for working with numbers, arrays, and mathematical operations.

NumPy provides a high-performance data structure called an `ndarray` (n-dimensional array), which is much faster and more memory-efficient than using standard Python lists for numerical data.

```
import numpy as np
numbers = np.array([1,2,3,4,5]). # numbers is an ndarray
print(numbers*2)
```

You can calculate the average of an array of numbers:

```
print(np.average(numbers))
```

Similarly for the median:

```
print(np.median(numbers))
```
