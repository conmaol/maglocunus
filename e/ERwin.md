# ERwin Data Modeler

`ERwin Data Modeler` is a specialist data modelling and data architecture tool used to design, document, analyse and maintain an organisation’s data structures and database schemas. It allows data architects to create and manage conceptual, logical and physical data models.

Capabilities of ERwin Data Modeler are:
- visual ER diagrams
- reverse-engineering existing databases into models
- forward-engineering models into database schemas
- data dictionary generation
- impact analysis
- version control and collaboration
- metadata management and governance integration.

As of 2026, ERwin Data Modeler seems to have been subsumed into the [Quest Trusted Data Management Platform](https://www.quest.com/data-management-platform).

Similar modelling tools are:
- ER/Studio
- SAP PowerDesigner
- Oracle SQL Developer Data Modeler
- Sparx Enterprise Architect
- Lucidchart (lighter-weight modelling)
- Microsoft Visio (basic modelling)
